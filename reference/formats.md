# Formats: sizes and what each one needs

Width x height in CSS pixels (the page size). Render with `--scale 2` for the final file unless noted.

| Format | Size | Scale | Notes |
|---|---|---|---|
| YouTube thumbnail | 1280 x 720 | 1 (or 2 for a sharp master) | max 4 words, readable at 160 px wide; bottom-right corner is covered by the time stamp |
| YouTube banner | 2560 x 1440 | 1 | everything important inside the centre 1546 x 423 (safe area on all devices) |
| Instagram / Facebook post | 1080 x 1350 | 1 | 4:5 portrait wins the feed; square 1080 x 1080 also fine |
| Story / Reel cover / TikTok | 1080 x 1920 | 1 | keep the top 250 px and bottom 340 px free of text (app buttons) |
| LinkedIn / X post image | 1200 x 675 | 2 | |
| Poster A3 / A4 (portrait) | 794 x 1123 | 4 | A-ratio 1:1.414; scale 4 gives about 300 dpi at A4 size; readable from 3 m |
| Flyer A5 / A6 | 559 x 794 | 4 | |
| Menu (A4 or A3 portrait) | 794 x 1123 | 4 | scannable: sections, item, short description, price aligned right with tabular numbers |
| Business card | 1050 x 600 | 3 | 85 x 55 mm with 3 mm bleed on each side; keep text 5 mm in |
| Web hero / banner | 1920 x 1080 | 1 | |
| Email header | 1200 x 400 | 2 | |
| App / avatar icon, logo mark | 1024 x 1024 | 1 | must read at 32 px: one shape, no small text |
| Event ticket | 1200 x 450 | 2 | |
| Etsy / shop product image | 2000 x 2000 | 1 | |

Anything else: ask where it will be used, find the platform's real size, and keep the important parts away from
edges that apps cover.

## What each one is for
- **Thumbnail**: one emotion or one claim, readable small, contrast against YouTube's white and dark themes. A big
  face (the user's own photo) plus up to 4 huge words, or a strong object plus 2-3 words. Never repeat the title.
- **Ad / social post**: the offer in under 2 seconds: what, for whom, why now, where. Brand visible but small.
- **Poster / flyer**: what, when, where, in that order of size. A date always with a weekday.
- **Menu**: easy to scan with a finger. Group by section, the best sellers marked once, prices aligned, no
  currency symbol clutter on every line (put it once in the header or use plain numbers).
- **Banner / header**: the name and one line, lots of calm space.
- **Logo / icon**: one idea (a symbol, monogram or negative-space trick), works in one colour and at tiny size.
